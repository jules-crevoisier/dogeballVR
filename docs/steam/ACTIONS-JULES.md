# Actions Steam que seul jules peut faire

Dans l'ordre. Les durées sont le temps passé devant l'écran ; les attentes de Valve sont à part. Personne d'autre (ni les agents) ne peut créer le compte, payer, signer ou remplir la fiscalité.

**À savoir d'abord** : Steam impose **30 jours** entre le paiement des frais et la sortie (page Steam Direct ; l'onboarding parle de 21 jours, prévoir 30), une page « Coming soon » publique **au moins 2 semaines** avant la sortie, et des revues de page et de build de 3 à 5 jours ouvrés chacune (prévoir 7). Le jeu ne peut donc pas être en vente sur Steam avant environ 5 à 6 semaines. Ce qui est possible tout de suite : tester les fonctions Steam avec le zip de test (AppID 480 Spacewar, `docs/LISEZ-MOI-test.txt`) puis, une fois l'app créée, une branche beta privée.

Les liens `partner.steamgames.com/apps/.../APPID` sont des liens types (remplacer APPID) ; leur forme exacte est à revérifier, la navigation passe sinon par le tableau de bord Steamworks.

Remarques :
- Étape 11 : le dossier des sauvegardes est fixé dans `project.godot` (`config/use_custom_user_dir`, nom `DogeballVR`) : `%APPDATA%/DogeballVR/` sous Windows, `~/.local/share/DogeballVR/` sous Linux. Il ne bouge pas si le jeu est renommé (sinon les sauvegardes et l'Auto-Cloud seraient perdus). Les versions de test d'avant le 22/10 rangeaient tout dans `Godot/app_userdata/DogeballVR/` : réglages à refaire une fois, rien d'autre.
- `settings.cfg` ne contient plus que les options qui suivent le joueur (touches, son, accessibilité, bots) ; vidéo et taille de l'interface sont dans `machine.cfg`, volontairement hors Steam Cloud (un Deck ne reçoit pas la qualité haute du PC). Ne pas ajouter de chemin pour `machine.cfg`.
- Étapes 12 et 13 : `docs/steam/achievements.csv` et `docs/steam/rich_presence_fr_en.vdf` sont dans le dépôt (PR #22) ; les noms API du CSV sont ceux qu'utilise le code, ne pas les changer.
- `ShippedAppId` (scripts/Online/Steam/SteamPlatform.cs) reçoit automatiquement l'AppID (secret `STEAM_APP_ID`) dans le workflow « Envoi Steam » : rien à faire à la main.

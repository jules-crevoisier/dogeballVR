# Mannequins et animations Quaternius

- `UAL1_Standard.glb` : Universal Animation Library, version Standard (46 animations, rig Rigify « DEF- »).
  https://opengameart.org/content/universal-animation-library
- `UAL2_Standard.glb` : Universal Animation Library 2, version Standard (mannequin homme, rig type Unreal, 43 animations).
  https://opengameart.org/content/universal-animation-library-2
- `Mannequin_F.glb` : mannequin femme livré avec UAL2, même rig.

Auteur : Quaternius (https://quaternius.com). Licence : CC0 1.0 Universal, domaine public
(https://creativecommons.org/publicdomain/zero/1.0/). Utilisable dans un jeu commercial, sans obligation de crédit.

`tools/blender/mannequin.py` en tire les avatars du jeu (`assets/models/avatar_*_rig*.glb`).
